# 뜀결 디자인 시스템

> 실시간 줄넘기 측정 시스템의 전역 시각 기준. 페이지별 파일이 있으면 해당 파일이 이 문서를 재정의한다.

## 방향

- 제품 유형: MediaPipe Pose 기반 실시간 피트니스 계측 도구
- 스타일: Tactical Telemetry 기반 Industrial Brutalism
- 핵심 원칙: 카메라, 점프 수, 남은 시간, 인식 상태가 장식보다 먼저 읽혀야 한다.
- 시각 변주 8/10, 모션 4/10, 정보 밀도 7/10

## 색상

| 역할 | 값 | 용도 |
| --- | --- | --- |
| Night | `#181818` | 전역 배경 |
| Surface | `#1F1F1F` | 카드와 패널 |
| Raised | `#272727` | hover 및 선택 상태 |
| Rule | `#313131` | 구조선과 트랙 |
| Phosphor white | `#EAEAEA` | 기본 텍스트 |
| Muted | `#9B9B9B` | 보조 텍스트 |
| Hazard red | `#E61919` | 주요 행동과 카운트다운 |
| Live green | `#4AF626` | 실제 실시간 연결과 인식 상태 |

Hazard red가 유일한 브랜드 강조색이다. Live green은 장식에 쓰지 않고 실시간 상태에만 사용한다. 일반 텍스트는 배경 대비 4.5:1 이상을 유지한다.

## 타이포그래피

- 디스플레이: `Satoshi`, 한글 대체 `Gothic A1`
- 본문: `Gothic A1`
- 데이터: `Geist Mono`, `SFMono-Regular`, `Consolas`, monospace
- 제목은 `text-wrap: balance`, 본문은 `text-wrap: pretty`를 사용한다.
- 변화하는 횟수, 시간, 표의 숫자는 `font-variant-numeric: tabular-nums`를 사용한다.
- 히어로 제목은 최대 두 줄, 전체 너비 1440px, `clamp(3rem, 8vw, 8rem)`이다.

## 공간과 격자

- 간격은 8px 계열을 기본으로 한다.
- 주요 장면 간격은 96–160px이다.
- 데스크톱 종목 선택은 12열 gapless grid다: 모아뛰기 7×2, 번갈아뛰기 5×1, 이중뛰기 5×1.
- 1000px 이하에서는 한 열로 바뀌고 카드가 순서대로 쌓인다.
- 375px, 768px, 1024px, 1440px에서 가로 스크롤이 없어야 한다.

## 표면과 제어

- 모든 카드, 버튼, 입력, 다이얼로그는 0px 직각 모서리를 사용한다.
- 구조는 1px Rule 선과 색면으로 나누며 정지 카드에 일반 그림자를 쓰지 않는다.
- 다이얼로그와 결과 오버레이에만 단단한 오프셋 그림자를 허용한다.
- 모든 버튼은 최소 44×44px, 주요 버튼은 48px 높이다.
- 버튼 누름은 `scale(.96)`, hover와 focus는 색·구조선·명시적 포커스 링으로 함께 표현한다.
- `transition: all`은 금지한다.

## 실시간 측정

- 카메라가 가장 넓은 영역을 차지하고 오른쪽 패널은 점프 수, 남은 시간, 상태 순으로 읽힌다.
- 점프 수는 가장 큰 고정폭 숫자다.
- 시간 진행은 `transform: scaleX()`로 갱신한다.
- Pose landmark는 Live green으로 표시한다.
- 실제 연결·신체 인식 상태만 Live green을 사용한다.
- 모션 감소 설정에서는 GIF 대신 포스터를 사용한다.

## 모션

- GSAP과 ScrollTrigger는 프로젝트에 로컬로 포함한다.
- 텔레메트리 스트립, 종목 카드의 스크롤 스케일·페이드, 모바일 카드 스택만 움직인다.
- 모든 고빈도 상호작용은 150–220ms의 중단 가능한 CSS transition만 사용한다.
- `prefers-reduced-motion: reduce`에서는 반복과 스크롤 모션을 제거하고 최종 정적 상태를 즉시 렌더링한다.

## PDF 기록

PDF에는 다음 측정 사실만 포함한다.

- 사용자
- 종목
- 점프 횟수
- 측정 시간
- 측정 상태
- 측정 시작 시각과 기록 번호

칼로리, MET, 평균 페이스, 자세 추천, 운동 또는 의학 안내는 포함하지 않는다.

## 최종 검수

- 키보드 포커스가 보인다.
- 아이콘 전용 버튼에 접근 가능한 이름이 있다.
- 색상만으로 상태를 구분하지 않는다.
- 표와 기록은 좁은 화면에서 안전하게 스크롤된다.
- 모달에 닫기 경로가 있다.
- 모션 감소 설정에서 콘텐츠가 사라지지 않는다.
- 외부 CDN 없이 CSP `self` 정책을 유지한다.
