# 외부 CC BY 영상 라벨 확인 안내 (Kinovea)

`clips/` 폴더에는 YouTube에서 **CC BY(저작자 표시)** 라이선스로 공개된 영상 중, 정면에서 줄넘기를 하는 구간만 잘라 둔 클립(최대 30초, 소리 없음)이 있습니다. 클립마다 같은 이름의 `.kva` 파일이 있고, 자동으로 찾은 **착지 후보**가 키프레임으로 찍혀 있습니다. 후보는 영상만으로 만들었고 소리는 쓰지 않았습니다. 틀린 것과 빠진 것이 섞여 있으니, 사람이 확인해서 고쳐야 정답 라벨이 됩니다.

후보 키프레임은 **발 움직임만으로** 찾았습니다. 줄 영상 신호는 줄걸림 의심 표시에만 썼습니다. 이름과 색은 다음 뜻입니다.

| 이름 | 색 | 뜻 | 먼저 볼 것 |
|---|---|---|---|
| `ok` | 초록 | 직전 착지와의 간격이 평소 리듬 범위 안 | 대체로 맞음 |
| `check` | 빨강 | 간격이 너무 짧거나 김 | 빠진 점프, 중복 후보 |
| `trip?` | 보라 | 리듬이 끊긴 동안 발밑에서 줄 통과가 보이지 않음 | **줄걸림** 여부 |
| `double?` | 초록 | 이중뛰기 모드에서 손 회전이 점프의 약 2배 | 대체로 이중뛰기 |
| `single?` | 노랑 | 이중뛰기 모드에서 손 회전이 점프와 같은 속도 | 한 번만 돈 점프라면 삭제 |
| `first` | 주황 | 클립의 첫 착지 | 앞부분 확인 |

## 점 위치
각 후보 키프레임에는 그 프레임의 관절 추정값으로 착지 위치에 점을 찍어 두었습니다. 점이 발에서 벗어나 있으면 관절 추정이 틀린 프레임이니 시점도 함께 확인합니다.

| 종목 | 점 |
|---|---|
| `basic` 모아뛰기 | 착지한 **양발 끝의 가운데**에 점 1개 |
| `alternating` 번갈아뛰기 | **착지한 발의 발끝**에 점 1개. 키프레임 이름 뒤에 `왼발`/`오른발`이 붙습니다(사람 기준 좌우라서 정면 영상에서는 화면의 반대쪽). |
| `double` 이중뛰기 | **양발 끝에 각각** 점 2개 |

`manifest.csv`의 `needs_check` 열은 클립별로 빨강·보라·노랑 후보가 몇 개인지 보여 줍니다.

출처(URL, 업로더, 라이선스)는 `manifest.csv`와 `../ATTRIBUTION.md`에 있습니다. 클립과 원본 영상은 Git에 올리지 않습니다.

## 작업 순서
1. Kinovea에서 `clips/<이름>.mp4`를 엽니다.
2. 같은 이름의 `.kva`가 자동으로 불러와지지 않으면 **파일 → 주석 불러오기**로 `clips/<이름>.kva`를 엽니다.
3. 프레임 단위로 넘기며(← →) 아래 기준대로 키프레임을 고칩니다.
   - 틀린 후보는 키프레임을 삭제합니다.
   - 빠진 점프는 해당 프레임에 키프레임을 추가하고, 위 **점 위치** 기준대로 연필로 점을 찍습니다(번갈아뛰기는 이름에 `왼발`/`오른발`도 적어 주세요). 빈 키프레임은 무시됩니다.
4. 같은 이름의 `.kva`로 덮어써서 저장합니다.
5. `manifest.csv`에서(위에서부터 `priority` 순서, 1~6이 이중뛰기) 그 클립의 `verified`를 `yes`로 바꿉니다. 쓸 수 없는 클립은 `no`로 두고 `notes`에 이유를 적습니다(줄 없음, 화면 잘림, 다른 동작 등). 중간에 측면으로 돌아서는 클립은 `use_until_sec`에 정면이 끝나는 시점(클립 기준 초)을 적으면 그 앞까지만 씁니다.
   - `manifest.csv`를 엑셀로 저장하면 `-`로 시작하는 영상 ID가 `#NAME?`으로 바뀝니다. 도구는 클립 파일 이름에서 ID를 다시 읽으므로 결과에는 영향이 없습니다.
   - **자동 후보를 고치지 않고 `yes`로 바꾸면 틀린 후보가 그대로 정답이 됩니다.** 2026-10-14 점검에서 `CfbJKAw83Qw` 두 클립은 실제 점프의 절반만 후보가 있었습니다.

## 계수 기준 (기존 벤치마크 라벨과 같음)
| 종목 (`mode`) | 키프레임 1개 = |
|---|---|
| `basic` 모아뛰기 | 줄을 넘고 **양발이 착지한 프레임** 1회 |
| `alternating` 번갈아뛰기 | 줄을 넘고 **발이 바뀌어 착지한 프레임**마다 1회. 한 발 착지마다 1회입니다. |
| `double` 이중뛰기 | **줄이 두 번 돈 점프**의 착지 프레임 1회. 한 번만 돈 점프의 후보는 삭제합니다. |

## 줄걸림 표시
- 줄이 발이나 다리에 걸린 장면은 걸린 프레임에 키프레임을 만들고, **이름을 `trip`(또는 `걸림`)으로 바꿉니다.** 점도 하나 찍어 둡니다.
- 걸린 그 점프는 성공한 점프가 아니므로, 그 점프의 착지 후보가 있으면 삭제합니다.
- 이 표시는 줄걸림 감지를 검증하는 데 씁니다. 지금은 실제 걸림 데이터가 하나도 없어서 가장 귀한 라벨입니다.
